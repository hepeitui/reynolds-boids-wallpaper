# Reynolds 群飞壁纸

离线 WebGL2 实时鸟群。默认 1000 只，数量范围 0–3000；二维局部群飞、提前回转、触边死亡动画与补生、画外分批进出场、点击排斥及短时 10% 速度增益、按秒计时且可在暂停时重设的拖尾。

## 打开与操作

直接打开本目录 `index.html`，或工作区根目录 `flock-wallpaper.html`。无需安装依赖、联网或构建。需要 WebGL2 硬件加速；不支持时显示兼容提示，不会偷偷回退到 Canvas2D。

- 开发面板即时保存所有设置。滑块与数值框同步；数值非法时保留原值，越界时限幅。
- 鼠标移动：附近鸟群避让。点击：衰减排斥，附近鸟获得自身常态速度的 10% 增幅，重复点击刷新时长而不叠加。
- 暂停按钮或空格：冻结模拟与轨迹时间；此时修改拖尾时长、颜色、亮度或开关会立即重画已有历史。
- 收起面板：观看完整画面。URL 参数 `?desktop=1` 隐藏开发界面，`?settings=1` 强制显示开发界面。
- “导出设置”生成 JSON 报告，包含设置、种子、当前统计与环境；没有开启测量时不虚构帧时间分布。
- 无鸟且残影消退后，停止周期更新；改变数量可重新唤醒。页面隐藏及宿主暂停采用冻结时间语义。
- 活动鸟触边后停止飞行，约 0.28 秒内展开/闪亮/淡出，随后按最新目标数量从画外补生；入场与主动离场允许越界。归零不会触发额外补生，暂停也冻结死亡动画。

## 外观与活动区域

- 默认鸟体大小 **4px**，拖尾时长 **0.8 秒**；分别由 3px 和 1.2 秒调整，鸟体更醒目、轨迹更短。
- 默认亮度 **1.15×**、对比度 **1.2×**；颜色不再被固定混成青白色。“鸟群渐变配色”使用连续的空间色相场，靠近的鸟颜色相似，飞行时平滑变色；鸟体、拖尾及离场残影在相同位置使用相同色相，拖尾沿轨迹渐变。关闭后立即恢复所选统一颜色。已保存的随机配色开关及 Wallpaper Engine 属性自动使用新效果。
- 左、右、上、下边距独立调整，默认均为 **18px**，范围 0–200px。它们叠加在可用工作区内；小窗口中自动同比缩减过大的对边留白，保留可用内部区域。
- “避开任务栏”默认开启：在单屏尺寸的壁纸画布中，读取 `screen.availLeft/availTop/availWidth/availHeight`，排除工作区外的任务栏区域，每两秒检查变化。普通非全屏浏览器预览不会据此错误裁剪。
- Web 页面无法直接调用 Windows 任务栏 API。宿主未提供真实工作区、跨屏壁纸或自动隐藏任务栏时，不能保证自动识别；请手动增加相应侧边距。任务栏区域及边距外不绘制鸟体或拖尾。
- 边缘回转区默认从 10% 提高到 **18%**，可调 0–35%；根据速度预留转弯距离，向内权重从 4 提高到 6，并为正面冲边提供侧向转弯。仍保留真正触边的死亡动画；调整留白或缩小窗口不会整片杀死被排除的鸟，而是引导重新进入。
- 数值设置使用线性滑条与数值框：浮点属性细化到 0.01（边缘区 0.001），帧率 15–120 FPS、拖尾采样率 10–60 Hz 均可逐整数拖动。模式仍是分类选项。
- 已保存的用户设置继续保留；新的默认值只用于未保存的属性。旧配置若仍为亮度 0.8、边缘区 10%，可直接拖到上述推荐值。

## Wallpaper Engine

1. 编辑器选择“创建壁纸”，导入此目录的 `index.html`，不要导入整个工作区。
2. 本目录附带手写 `project.json`，已定义 25 个属性。**它不是编辑器生成、审定的发布配置**；导入后核对入口 `index.html`、Web 类型、预览图及所有属性。若编辑器重新生成配置，保留或重新建立同名属性。
3. 应用壁纸，通过 Wallpaper Engine 右侧属性面板调整。开发界面会在收到宿主通知时隐藏；资源完全本地化。
4. 宿主导入会复制资源。修改原文件后，必须同步宿主副本；工作区提供 `node work/stage-host.cjs`，复制到本机的专用审查目录并输出 SHA-256 一致性记录。
5. 此机命令行在中文路径打开项目曾出现路径乱码，使用 ASCII 宿主副本目录成功。普通浏览器直接打开中文路径已列入验证。遇到同类 CLI 问题，优先编辑器导入或使用不含非 ASCII 字符的副本，不改系统编码。
6. 全局 FPS 与项目 FPS 取较低上限。帧率滑条只改变绘制上限，不暗改鸟数、速度、权重或颜色。渲染比例和拖尾采样质量单独可见。
7. 桌面输入是否转发由宿主配置决定；没有输入仍正常群飞。桌面图标区域、多显示器、软件重启及最终呈现稳定性需要在实际桌面单独验收。

### 小数滑条步长修复

`project.json` 的 10 个小数滑条已显式配置 `step`：速度差异、分离/对齐/聚合权重、鸟体大小、拖尾时长、亮度、对比度、渲染比例使用 `0.01`，边缘回转区使用 `0.001`。整数属性不变；属性名、范围、默认值和回调数值单位均不变。

原因是本机 Wallpaper Engine 属性面板使用 `step: property.step || 1`；仅有 `fraction: true` 和 `precision` 不会生成小数步长。手写配置缺少 `step` 时会按整数跳变，尤其使范围不足 1 的属性无法细调。保存格式与编辑器保持一致：`0.01` 对应 `precision: 3`，`0.001` 对应 `precision: 4`（编辑器保存时精度字段比界面小数位数多 1）。

修改后重新选择并应用壁纸；如果面板仍按旧步长移动，退出并重启 Wallpaper Engine 以重新读取项目配置。导入到其他目录的副本需要同步更新 `project.json`，只刷新网页不足以更新宿主属性面板。

验证：使用本机宿主的滑条选项表达式生成输入，遍历 20 个数值属性的全部 7192 个合法步进值，通过真实 `applyUserProperties` 回调与设置归一化；修复前 10 个小数属性会丢失最小增量，修复后全部通过。实际浏览器页面另验证了这 10 个属性的 30 次小数/中间值/上界回调，运行时设置与面板同步，WebGL2 渲染可用。未自动操作 Wallpaper Engine 桌面属性面板，桌面拖动及配置重新加载仍需宿主实测。

官方依据：[属性与回调](https://docs.wallpaperengine.io/en/web/api/propertylistener.html)、[用户属性](https://docs.wallpaperengine.io/en/web/customization/properties.html)、[命令行控制](https://help.wallpaperengine.io/en/functionality/cli.html)。

## 模式与性能

| 模式 | 邻域语义 | 定位 |
| --- | --- | --- |
| 半径 `radius`（默认） | R=58 内全部有效邻居 | 完整行为基线；高密度可能接近平方开销 |
| 网格 `grid` | R=58 内精确最近 K | 与动态图相同 K 语义的对照 |
| 动态图 `graph` | R=58 内近似最近 K | 实验项；独立网格校准、代次验证、每步精确短距离分离 |

K 可调 1–48，初始 16；动态图刷新 10–30 Hz，初始 15 Hz。图的质量与总成本必须一起看，不能因为候选少就当成无条件优于网格。当前默认不自动选择动态图、不自动降低画质。

当前单元边长为 40 逻辑像素，查询按实际半径扩大单元范围。完整落在圆内的单元采用精确加法聚合，圆边界与分离项仍做逐候选距离判断；保留逐鸟精确查询作为参考。动态图已在多场景准入测试中低于建议 recall 门槛，因此**未获准成为默认**；这不是已达标的第二套正式后端。

渲染为两次批量提交（有拖尾时）：实例化拖尾线段与实例化鸟体。历史固定保留至少 2.5 秒的 60 Hz 采样，10–60 Hz 属性调整展示密度；时间端点在着色器中插值。离场残影有独立固定容量，溢出统计会在报告中显示。亮度与对比度为统一参数；渐变色相由共享的 GPU 空间函数计算，不依赖鸟的槽位、代次或随机数。鸟体实例与拖尾线段各使用 6 个浮点数，不再上传逐鸟色相。

历史按版本缓存：采样、退场或轨迹设置变化时重建，其他帧只更新连接鸟体的头部。关闭拖尾、暂停调参和 WebGL 上下文恢复均保留一致的历史语义。

细线的几何包围像素滤波足迹，再按真实线宽计算覆盖率；不会仅因小数像素平移就整条消失。边缘区用于提前回转，宽度为零只关闭提前回转；真正触及活动区域边界的鸟死亡，不再飞出又返回。画面按活动区域裁剪，清屏仍覆盖整个画布，避免边距改变后留下旧画面。

历史时间戳在 CPU 使用 Float64，上传 GPU 时减去 1024 秒时间窗口的原点；窗口变化会使历史缓存失效，拍翼使用周期相位。避免运行时间很大时 Float32 秒数重合导致轨迹断裂。大时钟偏移回归不代替真实连续运行测量。

## 开发验证

以下命令在工作区根目录执行，交付运行不依赖这些工具：

```sh
npm --prefix work ci
node work/verify-behavior.cjs
node work/verify-neighbors.cjs
node work/verify-settings.cjs
node work/check.cjs
node work/verify-boundary-death.cjs
node work/verify-death-render.cjs
node work/verify-browser.cjs
node work/verify-trail-coverage.cjs
node work/verify-trail-coverage.cjs --ratio=0.5
node work/verify-trail-coverage.cjs --ratio=2
node work/verify-trail-coverage.cjs --uptime=864000
node work/verify-trail-coverage.cjs --cross-epoch
node work/benchmark.cjs --quick
node work/benchmark.cjs
```

浏览器类命令需要服务器：先在另一个终端运行 `node work/serve.cjs`，保持其运行，再执行相应验证；纯逻辑回归不需要服务器。

浏览器验证与性能程序使用本机已安装 Chrome，以可视窗口运行。`benchmark.cjs` 每组预热 60 秒、采样 180 秒，覆盖空背景控制、500/1000/2000/3000 的默认与最大拖尾、3000 只网格 K / 图交替三次，JSON 和源码 SHA-256 保存在 `work/measurements/`。需要先启动预览服务器；`--quick` 仅用于冒烟，不能作为正式验收。**按用户最新要求，默认不再执行 30 分钟连续测试，也不以此阻碍交付。** 工具保留显式 `--long` 选项，但本轮不运行。时长覆盖参数始终保存实际值，不把短测写成长测。

无人值守长测时，可在另一个终端运行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File work/hold-measurement-awake.ps1`。它只绑定正在运行的本项目 benchmark 进程，临时防止系统空闲休眠/灭屏；进程结束或最多 3 小时后释放，不改变永久电源方案，也不阻止用户主动休眠。壁纸交付目录不包含、也不会自动运行这个工具。

开发控制台 `boids.startCapture()` / `boids.stopCapture()` 获取提交间隔分布；`boids.quality(128)` 运行独立近邻真值诊断，**不要在性能采样期间调用质量诊断**。`boids.report()` 记录当前设置、显卡、像素尺寸、CPU 模拟及上传量。GPU 时间来自异步查询，扩展不可用时为空。

`node work/verify-graph-motion.cjs` 是实验图的**准入检查**，当前会因 recall 未达门槛返回非零，并把全部测量写入 `work/graph-motion-result.json`；失败未被删除或改成通过。`node work/check.cjs --qualification` 同时保存该红灯结果。正式默认模式的回归用不带此参数的 `check.cjs`。

此前外观/边界调整的核心回归覆盖正面冲边、最高速度转向、独立留白、工作区四边及负坐标显示器、设置中间值保存。相同种子 300 只 / 60 秒场景，触边死亡由修改前 110 次降到 3 次。此前浏览器拖动及 WebGL 像素验证见 `work/appearance-boundary-result.json`；其中逐鸟随机颜色的记录属于旧效果。本次渐变配色另经实际浏览器画面及 WebGL 像素冒烟验证：相邻鸟颜色相近、远处颜色渐变、移动连续、重生代次不影响颜色、拖尾及离场残影沿用相同空间色相、缓存重绘稳定、关闭渐变恢复统一颜色。物理桌面任务栏的实际识别仍须宿主提供正确工作区，不能用模拟工作区回归冒充桌面实测。

浏览器可见性自动化有一项明确限制：此环境切后台页签、最小化窗口及取消焦点模拟后仍返回 `visible`。程序没有伪造 `document.hidden` 来制造通过记录；实际隐藏/恢复事件仍列为未验证，手动暂停与宿主暂停回调已单独验证。

## 结构

- `host.js`：提前注册宿主回调与缓冲通知。
- `settings.js` / `ui.js`：统一设置验证、保存与开发面板。
- `neighbors.js`：网格、动态图与真值诊断。
- `simulation.js`：生命周期、局部规则与快照积分。
- `history.js`：时间戳环形历史、代次隔离与离场残影。
- `renderer.js`：WebGL2 程序、实例化上传、GPU 计时及上下文恢复。
- `app.js`：固定时间步、绘制节拍、暂停与运行报告。
